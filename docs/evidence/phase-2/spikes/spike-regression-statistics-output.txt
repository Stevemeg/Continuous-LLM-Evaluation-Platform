==============================================================================
CONCLUSION
==============================================================================
The decisive finding is not the false-positive rate. At n=200 the naive
threshold produced the FEWEST false positives of the three methods, because a
fixed 0.02 threshold becomes very conservative once the sample mean
concentrates. That is not a virtue: the same fixed threshold makes it fire on
pure noise in roughly one run in six at n=20, and makes it structurally unable
to detect any real regression smaller than the threshold at any sample size.
Its behaviour is governed by an arbitrary constant rather than by the evidence,
which is precisely the 'arbitrary quality-gate score without uncertainty' that
canonical section 25 rejects.

The decisive finding is ABSTENTION. At n=20 the bootstrap declines to classify
in roughly nine trials in ten -- including when the true effect is large --
because the interval is genuinely too wide to distinguish anything. At the same
sample size the naive method issues confident regression verdicts on pure
noise. One method reports that it cannot tell; the other guesses.

Against the requirements:
  REQ-F-08-2 uncertainty and effect size : bootstrap YES (interval + dz)
                                           permutation partial (p only)
                                           naive NO
  REQ-F-08-4 insufficient-evidence state : bootstrap YES
                                           permutation NO, naive NO
  REQ-F-08-1 detects real regressions    : bootstrap YES at adequate n
  REQ-F-08-3 minimum-sample guidance     : bootstrap YES, derived from the
                                           detection table above

The paired bootstrap percentile interval is therefore the only candidate that
satisfies all four requirements. The permutation test is retained as a
cross-check for a future spike, not as the primary method, because it cannot
abstain.

A second finding constrains the product directly: a noise-scale effect
(-0.01) is not reliably detectable even at n=200. Minimum-sample guidance must
therefore be stated per effect size, and the product must refuse to claim
detection of effects below what the sample supports rather than reporting a
small delta as a verdict.

LIMITATIONS. Simulated scores from one distribution family; one noise level;
independent samples; a single alpha and precision setting; 100 trials per cell,
so rates carry sampling error of a few counts. This spike supports a
METHOD-CLASS decision only. Production alpha, per-metric precision thresholds,
and minimum-sample tables must be set from real evaluation data, and the
percentile bootstrap's known small-sample undercoverage should be re-examined
against a bias-corrected variant before those values are fixed.
